## 3. Executive Findings

1. **GBDT is the clear winner** across every strategy/horizon pair in test MAE(log).
   - Best overall config: `gbdt | concat | h=7` with `test_mae_log=1.112712`.
2. **7-day horizon is easier and more separable** than 30-day for all families.
   - Error increases from h=7 to h=30 are smallest for GBDT and largest for Ridge.
3. **Ridge is weakest overall**, especially at 30-day horizon where one config has negative test R2.
4. **Gated Fusion MLP results are identical across strategies** for each horizon (same metrics repeated), indicating strategy has no effective impact in this run setup for that architecture.
5. **Text-absent slice is harder** for all families, but GBDT is much less sensitive to text presence.

## 10. Evaluation for Report Generation

### 10.1 Recommended Primary Model for Reports
- **Champion model**: `gbdt`
- **Preferred default config**: `strategy=concat`, `horizon=7` for shortest-horizon reporting.
- **Preferred 30-day config**: `strategy=concat`, `horizon=30` (best 30-day MAE among all tested configs).

### 10.2 Why this choice is defensible
- Best score on every comparative axis in this run set:
  - Lowest MAE(log)
  - Best or near-best RMSE(log)
  - Highest test R2(log), especially at 30-day horizon
  - Strongest correlation and lightest residual tails
  - Lowest degradation from 7-day to 30-day
  - Lowest sensitivity to text-presence slices

### 10.3 Secondary model recommendations
- If a neural baseline is required for narrative or ablation, use `concat_mlp` (better than gated MLP and ridge in this snapshot set).
- `ridge` should be treated as a weak baseline only.

### 10.4 Important caveats for generated reports
- Raw-scale metrics (`*_raw`, `MAPE`) are highly unstable due heavy-tailed view counts and near-zero denominators.
- Prefer log-scale metrics (`mae_log`, `rmse_log`, `r2_log`) as primary report KPIs.
- The gated model showing identical results across strategies warrants a pipeline check before claiming strategy sensitivity for that family.

## 11. Quality Checks and Suggested Follow-Ups

1. Add explicit checks to flag identical metrics across strategies for any model family.
2. Add robust raw-scale diagnostics (e.g., median absolute percentage-like metrics with denominator clipping) to reduce outlier distortion.
3. Track hard-case video_ids (top residual outliers) and inspect feature completeness/data quality.
4. Add confidence intervals via bootstrap on test MAE(log) for the winning configs.
5. Keep March 6 run selection policy explicit in future reports (latest complete run per family) to avoid partial-run bias.
